# TaskKeeper
Mobile (Android) task management app for small dev teams, designed to fill a gap between Jira and simple personal task lists. This is my final project for my Engineer's Degree at WSB-NLU in Nowy Sącz

# Features
- Create a project & a new version, then create tasks(or subtasks) and assign them to project members
- Invite your colleague simply by sending them your project's invite code
- By default, project managers have more rights than other users, but they can nominate other project members to become managers as well
- Accounts are required but not restricted - any account can create their own project, and be a part of other projects at the same time
- Works asynchronously, meaning project changes will show up instantly without the need to reload them
- Supports offline usage - your work will be synchronized automatically the next time you're online
- Receive notifications whenever a project or task is created/updated/removed
